# Changelog

## 1.61.0-0-SNAPSHOT

- Initial Java 8-compatible SDK implementation for Agones 1.61.x.
- Lifecycle, health, GameServer query/watch, metadata, Counters and Lists APIs.
- Blocking and CompletableFuture call styles.
- Optional Micrometer and JDK Flow modules.
- Spring Boot 2.7 auto-configuration and lifecycle management.
- Testcontainers wrapper for the Agones 1.61.0 SDK Server local mode.
